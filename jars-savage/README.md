# jars-savage

Pasta de **artefatos prontos para deploy** (gerada pelo Gradle).

```bash
.\gradlew.bat exportJarsSavage
```

| JAR | Servidor |
|-----|----------|
| `auth.jar` | Auth (Paper) |
| `lobbyhost.jar` | Lobby / Hub (Paper) |
| `game.jar` | Semi-anarquia (Paper) |
| `eventos.jar` | Eventos (Paper) |
| `proxyhost.jar` | Velocity (proxy) |

Os builds originais continuam em `<modulo>/build/libs/`.
